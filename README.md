## World Miilitary Spending 2021

This work is my capstone for MS Data Analysis and Visualization. This scroll-event-driven visualization implemented using [Scrollama](https://github.com/russellsamora/scrollama) and [D3.js](https://d3js.org) combines text, map, and data graphics to provide insight observable from the military spending data set from [SIPRI](https://www.sipri.org/databases/milex). This project explores the potential of interactive data visualization taking a new role, replacing contemporary printed media by emphasizing graphical elements rather than text in communicating complex ideas.
