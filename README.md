## World Miilitary Spending 2021

This work is my capstone for MS Data Analysis and Visualization. Showcasing interactive infographics activated with mouse-scroll event powered by [D3.js](https://d3js.org) and [Scrollama](https://github.com/russellsamora/scrollama). Built using [SIPRI](https://www.sipri.org/databases/milex) data. <br><br>
For abstract and full demo please refer:
- https://hhur0104.github.io/data_vis_capstone/
- https://academicworks.cuny.edu/gc_etds/5357/
